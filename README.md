# Альбом воспоминаний

Electron-приложение: фото + мысли + музыка + календарь. Дизайн — бумажный UI-кит из `design/` (`css/kit.css` скопирован без изменений).

## Что где лежит

- корень репозитория — Electron-приложение;
- `mobile/` — Android-сборка на Capacitor;
- `apk/` — готовые APK: пустой альбом и альбом с шестью демо-днями;
- `design/` — ранние бумажные макеты;
- `examples/` — шесть демо-дней и общая лента для жюри;
- `SUBMISSION.md` — описание проекта для жюри.

## Запуск

```bash
pnpm install
pnpm start
```

Если pnpm нет, подойдёт npm: `npm install && npm start`.

Демо-дни (6 штук) уже лежат в профиле приложения. Чтобы залить их заново на чистой машине:

```bash
node demo.mjs
pnpm start
```

`node demo.mjs --force` заменяет существующие дни демо-набором.

Если pnpm пишет `Ignored build scripts: electron`, разрешите сборку и повторите:

```bash
pnpm approve-builds --all
pnpm install
```

## Что умеет

- **Добавить** — фото (копируется в профиль приложения), текст, дата, настроение, песня.
  Песня подбирается сама по тексту и настроению (исполнитель, название, ссылка на поиск трека);
  можно вписать свою или вставить прямую ссылку на сервис. Ссылка открывается в браузере,
  трек не скачивается.
  Форматы фото: jpg, png, webp, gif, avif; файл проверяется по сигнатуре, переименованный текст не примется.
- **Песня влияет на воспоминание** — характер (тихая / средняя / громкая) меняет обработку фото
  (мягче или контрастнее), наклон кадра и темп сгенерированной музыки. Название песни задаёт
  мелодию, поэтому один и тот же день звучит одинаково. Автоподбор — только общественное достояние
  (классика и рэгтайм), ссылка ведёт на поиск записи на YouTube; аудио не скачивается.
- **ИИ** — кнопки «Улучшить текст» и «Подобрать стиль» (палитра, наклейки, музыка) через DeepSeek.
  В подбор стиля передаётся и песня. Без ключа стиль подбирается локально по словам текста и песни,
  приложение работает сразу.
- **Ключ** — DeepSeek-ключ встроен в сборку (`src/bundle.mjs` для десктопа, `src/bundle-web.mjs`
  для Android; AES-256-GCM, части собираются в рантайме) и расшифровывается на месте: жюри ничего
  не вводит. Свой ключ можно задать в настройках десктопа — он главнее встроенного. Ключ не попадает
  в рендер; запросы к DeepSeek идут из main-процесса (в APK — из WebView).
- **Музыка** — генерируется локально (Web Audio) из названия песни и настроения: свой темп, лад,
  мелодия при каждом открытии. Кнопка ▶ на карточке. Ссылка на настоящую песню — в подписи фото.
- **Наклейки** — сердце, бант, кассета, искра, скотч, пластырь. Позиции фиксированные, набор даёт ИИ.
  Поверх кадра всегда есть кусочек скотча — своя бумажная деталь, не от ИИ.
- **Календарь настроения** — снизу только неделя: цвет клетки = настроение дня, клик открывает день.
  «Год» разворачивает 12 месяцев с цветными клетками, «итоги» — чек-ап месяца: заголовок по частому
  настроению, статистика, коллаж фото и главная песня месяца. В первые дни нового месяца чек-ап
  открывается сам (один раз).
- **Звуки** — тихие бумажные щелчки и шорох при открытии шторок, сохранении, лайке и листании недель.
  Включаются и выключаются в настройках.
- **Стрелки в шапке** — листать заметки, не трогая календарь.
- **Лайк, изменение, удаление** — лайк на фото, карандаш/крестик под фото.

## Android

Мобильная сборка лежит в `mobile/`. Готовые APK — `apk/album-empty.apk`
и `apk/album-demo.apk` (шесть демо-дней). Подробности и пересборка — `mobile/README.md`.

## Где данные
`~/.config/album-memories/` (Linux):

```
notes.json      заметки (источник правды)
settings.json   ключ DeepSeek + модель
photos/         копии фотографий
days/           папки дней: <название>/note.json, text.txt, song.txt, photo.*
```

`days/` — витрина для жюри и проверки: при каждом сохранении папка дня пересоздаётся,
при удалении — удаляется. Источник правды остаётся `notes.json`, поэтому сбой экспорта
не ломает альбом. Название папки — название дня (3–7 слов), одинаковые названия получают
суффикс ` (2)`.

Файлы пишутся атомарно (`tmp` + `rename`), права `0600`. Фото, на которые не ссылается ни одна
заметка, удаляются при старте.

pnpm test          # node --test test/

Покрыты правила настроений/палитр/календаря и хранилище: валидация, обновление, удаление фото,
защита `photoPath` от выхода из папки, ключ не попадает в `getSettings()`.

## Чего пока нет

- облака и синхронизации (всё локально);
- загрузки аудиофайла песни — хранится только ссылка (по брифу этого достаточно);
- реального API генерации музыки — трек синтезируется на месте;
- загрузки фото по URL и камеры;
- нескольких окон и фонового воспроизведения.

DeepSeek выбран потому, что ключ обещали позже; замена провайдера — только `src/ai.mjs`.
