# O’Upon — Android APK

Мобильная сборка того же интерфейса. Внутри — WebView (Capacitor) и замена Electron-моста:
заметки и фото хранятся в `localStorage` телефона, фото сжимаются до 1400 px.

## Готовые APK

- `../apk/album-empty.apk` — пустая версия (`com.album.memories`).
- `../apk/album-demo.apk` — шесть демо-дней с фото (`com.album.memories.demo`).

Обе сборки debug-подписаны: ставятся через «Установить из файла» или `adb install`.
Разные package name, поэтому могут стоять одновременно.

## Что работает

- добавление, изменение, удаление дня; фото из галереи/камеры;
- настроение, песня (подбирается по настроению, можно вписать свою), ссылка открывается в браузере;
- календарь настроения: неделя снизу, год из 12 месяцев, чек-ап месяца с коллажем;
- звуки интерфейса (можно выключить), лайки, наклейки, генеративная музыка (Web Audio);
- данные сохраняются между запусками.

## Чего нет в мобильной версии

- DeepSeek-кнопки: ключ встроен и в APK, поэтому «Улучшить текст» и «Подобрать стиль»
  работают без настройки. Без сети стиль подбирается локально.
- Папок `days/` на диске: на Android данные лежат в `localStorage`.

## Пересборка

Нужны JDK 21 и Android SDK 36 (Capacitor 8 собирается под Java 21):

```bash
cd mobile
pnpm install
export JAVA_HOME=/usr/lib/jvm/java-21-openjdk
export ANDROID_HOME=$HOME/android-sdk
bash build-apk.sh
```

Скрипт берёт Gradle из `~/gradle-8.14.3/bin/gradle` (или `GRADLE_BIN`), собирает оба APK
и кладёт их в `dist/`.
