# Палитра «Альбома»

Источник истины — `css/kit.css`, блок `:root`. Здесь те же значения в читаемом виде.

## Базовые — бумага и чернила

| Переменная | Название | HEX |
|---|---|---|
| `--kraft` | крафтовая бумага (стол) | `#d6bd97` |
| `--kraft-deep` | тёмный крафт | `#c2a578` |
| `--kraft-light` | светлый крафт | `#e6d3b4` |
| `--paper` | кремовая бумага (карточки, кнопки) | `#fbf1dc` |
| `--paper-2` | вторичная бумага (hover, дорожки) | `#f0e2c6` |
| `--paper-3` | третичная бумага | `#e2d1ae` |
| `--ink` | чернила (контур, текст) | `#3b2c1f` |
| `--ink-soft` | мягкие чернила | `#3b2c1f` @ 62% |
| `--shadow` | жёсткая тень | `#b0906a` |
| `--ring` | светлое кольцо внутри контура | `#fffdf7` |

## Цветная бумага (палитры дней)

| Переменная | Название | HEX |
|---|---|---|
| `--pink` | розовый | `#f9a8c7` |
| `--mint` | мятный | `#a9e5b8` |
| `--sky` | небесный | `#93cdf3` |
| `--lemon` | лимонный | `#ffe27a` |
| `--lavender` | лавандовый | `#c3abe8` |
| `--coral` | коралловый | `#ffa487` |
| `--teal` | бирюзовый | `#8edfd3` |

`--accent` по умолчанию = `--mint` (`#a9e5b8`).

## Настроение → палитра

| Настроение | Палитра | HEX |
|---|---|---|
| радость (joy) | lemon | `#ffe27a` |
| покой (calm) | mint | `#a9e5b8` |
| нежность (love) | pink | `#f9a8c7` |
| грусть (sad) | sky | `#93cdf3` |
| ночь (night) | lavender | `#c3abe8` |
| драйв (bright) | coral | `#ffa487` |
| мечта (dream) | teal | `#8edfd3` |
